# KONİ 1.0

Arkadaşlarla birlikte izlemek ve dinlemek için ilk kararlı sürüm. Yalnızca **Windows 10/11 x64**.

**İndir** (GitHub hesabı gerekmez): https://github.com/Savas07/koni-releases/releases/latest
- `KONI_1.0.0_x64-setup.exe`: kurulum (önerilen; kendini günceller).
- `KONI_1.0.0_x64-portable.zip`: kurulumsuz; kendini güncellemez.

İmzasız: SmartScreen'de "Ek bilgi → Yine de çalıştır". Eski bir sürüm kuruluysa kendiliğinden 1.0'a geçer.

**Neler var**
- Odalar: Keşfet, Sinema ve Müzik modları; herkes aynı anda, senkron.
- Yerel dosya, YouTube ve web adresleri; "Herkes indirsin" ile önce indirip birlikte başlatma.
- "Ne izlesek?": birlikte oylayıp ortak filmi bulma.
- Profil, arkadaşlar, izleme listeleri, etkinlik akışı.
- Kendi sunucunu kurma (docs/SELF-HOSTING.md).

Sunucunun güncel olması gerekir (protokol p0.23).
